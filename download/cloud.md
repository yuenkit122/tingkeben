# 听课本 · 云服务说明

云服务只做一件事：让你的课程、课件、笔记、手写、录音转写和 API key 在几台设备之间自动同步。
**不登录也能正常用**，只是数据只在这一台设备上。

先看你是哪种情况：

| 你的情况 | 看哪一节 |
|---|---|
| 别人把听课本分享给你，还给了一个邀请码 | 一、用邀请码注册 |
| 你想把听课本分享给朋友，让他们用你的云 | 二、邀请朋友（云服务主人） |
| 你想有一个完全属于自己的云 | 三、自己建一个云服务 |
| 同步出问题了 | 四、常见问题 |

---

## 一、用邀请码注册（朋友看这里）

1. 打开听课本 → 左边「设置」→「云同步」→ 点 **我有邀请码，注册**。
2. 填邀请码（形如 `ABCDE-FGH23`，大小写、横线都无所谓）。
3. 自己定一个用户名（3–20 位，小写字母和数字）和密码（至少 8 位）。
4. 点「注册并登录」。之后这台设备会自动同步，不用再管。

换一台设备（比如 iPad、另一台电脑）：装好听课本 → 设置 → 云同步 → **登录**，填同一个用户名和密码。

需要知道的几件事：

- **一个邀请码只能注册一个账号。** 注册完邀请码就作废了，以后用用户名和密码登录。
- **你的数据和别人的分开存。** 别的用户（包括其他被邀请的人）看不到你的课程和笔记。
- **但是云服务的主人在技术上能看到。** 你的数据存在邀请你的那个人的 Cloudflare 存储桶里，他可以在自己的 Cloudflare 后台看到文件，其中包括你存到云端的 API key。信得过对方再用；介意的话有两个办法：不登录云服务（只在本机用），或者按第三节自己建一个。
- **有空间上限**（一般 1 GB，对方发邀请码时定的）。在「设置 → 云同步」能看到用了多少。满了课件就传不上去，删掉一些课件，或者请对方加空间。录音音频本来就不同步，不占云端空间。
- **忘了密码**：对方看不到你的密码，只能帮你重置成一个临时密码。拿到后登录，再到「设置 → 云同步 → 改密码」换掉。
- **改密码后**，你的其他设备要用新密码重新登录一次。
- **借别人的电脑用完**：设置 → 云同步 → 退出登录，勾上「同时清掉这台设备上的 API key」。

## 二、邀请朋友（云服务主人看这里）

你的云服务原来是「一个密码、一份数据」。把密码给别人，等于把你所有的课程、笔记和 API key 都给了对方。
升级之后，你仍然只用密码登录，数据原地不动；朋友各有各的账号，存在你的存储桶里另外的位置。

### 第一步：升级云端的 Worker（只做一次，约 5 分钟）

1. 打开 <https://dash.cloudflare.com> 登录 → 左边 **Workers 和 Pages** → 点进 `tingkeben-cloud`。
2. 右上角 **编辑代码**。把里面原来的代码全部删掉。
3. 打开这个项目里的 `cloud/worker.js`，全选复制，粘贴进去 → 右上角 **部署**。
4. 回到 Worker 的 **设置 → 变量和机密**，把 `APP_PASSWORD` 改成一个长一点的密码（至少 10 位，字母加数字）。
   以前的短密码在只有你自己知道网址时问题不大；现在安装包会发给别人，网址等于公开了，短密码很容易被试出来。
5. 改了密码之后，你自己的每台设备要用新密码重新登录一次（数据不会丢）。

怎么确认升级成功：浏览器打开你的云服务网址，看到 `"v":2` 就对了。

升级不影响旧设备：还没更新的旧版听课本（包括 iPad 上的网页版）照常能登录和同步。

### 第二步：发邀请码

1. 听课本 → 设置 → 云同步 → **邀请朋友 / 管理账号**。
   （看不到这个按钮？退出登录再登录一次，用户名留空、只填密码。）
2. 填备注（给谁的）、选空间上限 → **生成邀请码**。
3. 邀请码和使用步骤已经复制到剪贴板，直接粘贴发给朋友，连同安装包一起。

### 第三步：平时管理

同一个窗口里可以：

- 看每个人用了多少空间（大约 10 分钟更新一次）。
- **停用**账号：对方立刻登录不了、同步停掉，数据还在，可以恢复。
- **重置密码**：生成一个临时密码，只显示一次，发给对方。
- **作废**还没用的邀请码。

彻底删除某个人的数据，要到 Cloudflare 后台 → R2 → `tingkeben` 存储桶，删掉 `users/那个人的用户名/` 文件夹和 `accounts/那个人的用户名.json`。

### 费用和上限

Cloudflare 的免费额度（以 Cloudflare 官网当前公布的为准）：

| 项目 | 免费额度 | 大概够多少人 |
|---|---|---|
| R2 存储 | 10 GB | 你自己加上所有朋友的总和。每人 1 GB 的话，别超过 6–8 个人 |
| Worker 请求 | 每天 10 万次 | 一台设备开着听课本一小时约 250 次。十来个人日常用没问题 |

超过 R2 的 10 GB 会从你绑的卡上扣钱（按量计费，很便宜，但会扣）。所以发邀请码时别把上限加得超过 10 GB 的总数。

### 你要对朋友说清楚的

- 你在技术上看得到他们存在云端的东西，包括 API key。
- 你改 `APP_PASSWORD`、删存储桶、关掉 Cloudflare 账号，都会影响他们。
- 这是个人分享，不是商业服务，没有备份保证。重要的东西让他们在「设置 → 数据和备份」里定期导出。

## 三、自己建一个云服务（约 15 分钟，需要一张卡或 PayPal）

适合：不想把数据放在别人那里，或者想自己再分享给别人。

1. 注册 <https://dash.cloudflare.com/sign-up>（可以用 Gmail）。
2. 左边 **R2 对象存储** → 按提示开通（要绑卡或 PayPal，10 GB 以内不扣钱）→ **创建存储桶**，名字填 `tingkeben`。
3. 左边 **Workers 和 Pages** → **创建** → 选「Hello World」模板 → 名字填 `tingkeben-cloud` → 部署。
4. 点 **编辑代码**，把里面的代码全部换成 `worker.js` 的内容（找分享给你的人要这个文件，或者从听课本的代码仓库拿）→ **部署**。
5. 回到这个 Worker 的 **设置**：
   - **绑定** → 添加 → R2 存储桶 → 变量名填 `BUCKET`，存储桶选 `tingkeben`。
   - **变量和机密** → 添加 → 类型选「机密」→ 名称 `APP_PASSWORD`，值是你自己定的密码（至少 10 位）。
6. 记下 Worker 的网址，形如 `https://tingkeben-cloud.你的名字.workers.dev`。浏览器打开它，看到 `"ready":true` 就好了。
7. 听课本 → 设置 → 云同步 → **登录** → 展开「云服务网址」，换成你自己的网址 → 用户名留空，密码填 `APP_PASSWORD` → 登录。

之后你就是这个云服务的主人，可以按第二节给别人发邀请码。

## 四、常见问题

**登录时提示「连不上这个网址」**
检查网络。校园网有时会拦 `workers.dev`，换手机热点试一次。网址要以 `https://` 开头。

**提示「密码连错太多次」**
同一个网络连错 8 次会锁 15 分钟，等一会儿再试。

**提示「云端登录过期了」**
登录一次管 180 天；主人改了密码、你改了密码、账号被停用也会这样。重新登录就行，本机数据不受影响。

**提示「云端空间满了」**
见第一节的空间上限。笔记这类小东西仍然能同步，传不上去的是课件原文件。

**提示「这个云服务还是旧版」**
云服务的主人还没做第二节第一步的升级。

**同一台设备想换一个账号**
先在「设置 → 数据和备份」导出一份备份，再退出登录、登录新账号。本机已有的课程会合并进新账号。

**同步了什么、没同步什么**
同步：课程、课件（原文件和提取的文字）、笔记、画板手写、重点、聊天记录、录音转写、API key 和设置。
不同步：录音的音频文件（太大）。

**两台设备同时改了同一条笔记**
以后改的那份为准，被顶掉的那份会存成一条「（冲突副本）」，不会丢。
