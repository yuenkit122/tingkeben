# 听课本 · 云服务说明

云服务只做一件事：让你的课程、课件、笔记、手写、录音转写和 API key 在你自己的几台设备之间自动同步。

**只有一台设备可以不管这份说明。** 不登录云服务，所有功能照常能用，数据只在这一台设备上。

听课本不提供公共的云服务。要同步，就用自己的 Cloudflare 账号建一个，数据只在你自己手里，别人（包括听课本的作者）看不到。

| 你想做什么 | 看哪一节 |
|---|---|
| 建一个自己的云服务 | 一、自己建一个云服务 |
| 建好了，在其他设备上登录 | 二、在其他设备上登录 |

| 同步出问题了 | 四、常见问题 |
| 想把自己的云分给家人或室友用 | 五、（可选）邀请别人用你的云 |

## 一、自己建一个云服务（约 15 分钟，只做一次）

需要：一个邮箱，一张能在线支付的卡或 PayPal（开通存储时要绑，10 GB 以内不扣钱）。

### 1. 注册 Cloudflare

打开 <https://dash.cloudflare.com/sign-up>，用邮箱注册（Gmail 可以）。

### 2. 建存储桶

1. 左边菜单 **R2 对象存储** → 按提示开通（这一步要绑卡或 PayPal）。
2. 点 **创建存储桶**，名字填 `tingkeben`，位置选「自动」，创建。

### 3. 建 Worker

1. 左边菜单 **Workers 和 Pages** → **创建** → 选「Hello World」模板。
2. 名字填 `tingkeben-cloud` → **部署**。
3. 部署完点 **编辑代码**，把里面原来的代码全部删掉。
4. 下载 <https://yuenkit122.github.io/tingkeben/download/worker.js>，用文本编辑器打开，全选复制，粘贴进去 → 右上角 **部署**。

### 4. 把 Worker 和存储桶连起来、设密码

回到这个 Worker 的 **设置** 页：

1. **绑定** → 添加 → **R2 存储桶** → 变量名填 `BUCKET`（必须大写，一个字母都不能错）→ 存储桶选 `tingkeben` → 保存。
2. **变量和机密** → 添加 → 类型选 **机密** → 名称填 `APP_PASSWORD` → 值填你自己定的密码 → 保存。
   密码至少 10 位，字母加数字。这就是你以后在听课本里登录用的密码。

### 5. 确认建好了

在 Worker 页面上找到它的网址，形如 `https://tingkeben-cloud.你的名字.workers.dev`。
用浏览器打开，看到这样一行就对了：

```
{"app":"tingkeben-cloud","v":2,"accounts":true,"ok":true,"ready":true}
```

`"ready":false` 说明第 4 步有一项没设好，回去检查变量名。

### 6. 在听课本里登录

听课本 → 设置 → 云同步 → **登录**：

- 云服务网址：填第 5 步的网址
- 用户名：**留空**
- 密码：第 4 步定的 `APP_PASSWORD`

登录后会自动开始同步。之后改了东西几秒内自动上传，不用管。

## 二、在其他设备上登录

装好听课本（或打开网页版）→ 设置 → 云同步 → 登录，填同样的网址和密码，用户名留空。课程、笔记和 API key 会自动拉下来。

借别人的电脑用完：设置 → 云同步 → 退出登录，勾上「同时清掉这台设备上的 API key」。

---

## 三、不用云怎么搬数据

设置 → 数据和备份 → 导出，得到一个备份文件。拷到另一台设备，在同一个地方点导入。
这是一次性的搬运，不是同步：之后两台设备各改各的。

---

## 四、常见问题

**登录时提示「连不上这个网址」**
检查网址有没有抄错，要以 `https://` 开头。`workers.dev` 在中国大陆的网络通常直接打不开，需要能访问外网的网络环境。校园网偶尔也会拦，换手机热点试一次。

**浏览器打开网址显示 `"ready":false`**
Worker 没连上存储桶或没设密码，回到第一节第 4 步。

**提示「密码连错太多次」**
同一个网络连错 8 次会锁 15 分钟，等一会儿再试。

**提示「云端登录过期了」**
登录一次管 180 天；改了 `APP_PASSWORD` 也会这样。重新登录就行，本机数据不受影响。

**想改密码**
Cloudflare 后台 → Worker → 设置 → 变量和机密，改 `APP_PASSWORD`。改完每台设备重新登录一次，数据不会丢。

**会不会扣钱**
Cloudflare 的免费额度（以官网当前公布的为准）：R2 存储 10 GB，Worker 每天 10 万次请求。一个人用远远够。存储超过 10 GB 才会按量扣费；在「设置 → 云同步」能看到已经用了多少。录音音频不同步，不占云端空间。

**同步了什么、没同步什么**
同步：课程、课件（原文件和提取的文字）、笔记、画板手写、重点、聊天记录、录音转写、API key 和设置。
不同步：录音的音频文件（太大）。

**两台设备同时改了同一条笔记**
以后改的那份为准，被顶掉的那份会存成一条「（冲突副本）」，不会丢。

## 五、（可选）邀请别人用你的云

你建的云默认只有你一个人用。如果想分给家人或室友，不用把密码给对方：

1. 设置 → 云同步 → **邀请朋友 / 管理账号** → 填备注、选空间上限 → 生成邀请码。
2. 把邀请码和你的云服务网址发给对方。
3. 对方在听课本里：设置 → 云同步 → **我有邀请码** → 填网址、邀请码，自己定用户名和密码。

注意：

- 对方的数据和你的分开存，对方看不到你的；但你作为主人，在 Cloudflare 后台看得到对方的文件，包括对方同步上去的 API key。要跟对方说清楚。
- 对方占的是你的 10 GB，超了扣你的钱。
- 在同一个窗口里可以看每个人的用量、停用账号、重置密码、作废没用过的邀请码。
